# Admissions → Admission Replacement (Visual Aid)

This folder is a **shareable visual aid** for the UAGC content update process:
changing occurrences of **“Admissions”** to **“Admission”** across UAGC pages, including:

- Paragraph blocks (Tools Card, Completion Journey, Tools Section, Image Card Layout)
- URL aliases (example: `/admissions/masters` → `/admission/masters`)
- URL redirects for each degree level (Associate, Bachelor’s, Master’s, Doctoral, International)
- Content titles (example: “Master’s Admissions Requirements” → “Master’s Admission Requirements”)

## Open locally

Double-click `index.html`, or use any simple static server.

## Publish on GitHub Pages

Recommended approach:

1. Push this repo to GitHub under `williamhstokes`.
2. In GitHub: **Settings → Pages**
3. **Source**: “Deploy from a branch”
4. **Branch**: `master` (or `main`)
5. **Folder**: `/Admission Replacement/visual-aid`

Then GitHub will host `index.html` as a static site.

## Files

- `index.html`: the visual guide
- `src/styles.css`: UAGC-inspired styles (colors/typography)
- `assets/`: screenshots used as examples
